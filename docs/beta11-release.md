# Stock Loom 0.2.0-beta.11

修复 Computer Use 候选应用列表中可能遗漏窗口的问题。

- 获取应用程序路径改用 Windows `QueryFullProcessImageNameW` 与有限查询权限，避免因进程模块读取权限不足而隐藏可识别窗口。
- 保留应用授权及窗口身份校验，不提升应用权限。
- 本机国泰海通窗口识别、包内 MCP、UIA 写入与授权撤销验证通过；原故障电脑仍需复核。

安装后打开设置中的电脑操作，重新打开“添加应用”列表，再检查国泰海通。当前候选列表在打开时刷新，展开后不会自动刷新。

沿用 beta.10 的已知限制：UIA 历史偶发超时保留阶段诊断和恢复机制；200%缩放、多屏和独立机器安装未验证；Windows SDK DLL具体分发范围仍待核实，维护者决定继续使用当前依赖。安装包未作商业代码签名。
