# Stock Loom · 观市 v0.1.0-alpha.1

首个公开 Alpha：面向 A 股研究的本地桌面工作台。

## 本次提供

- 市场概览、行业板块、个股日线、财务与估值。
- 自选和手动持仓、项目文件浏览、多标签页与可调整布局。
- Codex Copilot、股票 MCP 工具、附件、权限选择以及 Plan / Goal 状态展示。
- 本地 Cron 调度与托盘后台运行。

## 安装

下载 `Stock-Loom-0.1.0-alpha.1-x64.exe`，可使用同页的 `SHA256SUMS.txt` 校验。安装包包含 Electron、数据服务和 Codex 运行时；使用行情及模型服务需要自己的账号或凭证。

本包未进行 Windows 代码签名，可能出现未知发布者提示。开发版的 `stock-workshop` 数据目录保持兼容。安装或升级前建议备份本地数据。

## 验证与限制

发布构建经过类型检查、Node / Python 自动化测试、打包资源和冻结数据服务校验，以及安装包目录内 Codex / MCP 运行验证。未进行异机安装验收。

仅提供 Windows x64。核心行情为日线和财务快照；并非实时交易终端，也不提供券商交易。第三方模型兼容性以实际服务协议为准。定时任务仅在应用打开或托盘后台运行时执行，退出后停止。Alpha 使用 Releases 手动升级。

项目采用 MIT 许可证，第三方运行时使用各自许可证；安装包内附许可文本与来源清单。
