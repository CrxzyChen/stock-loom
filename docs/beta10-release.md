# Stock Loom 0.2.0-beta.10

Round 5 测试版，新增独立 Computer Use 工具及 Copilot 集成。

- 支持持久 JavaScript 会话、Windows 窗口观察和截图、控件操作、点击、输入、滚动与拖动。
- 增加应用授权、会话状态和停止入口；操作失败保留实际错误及超时阶段，支持回收后重置。
- 整理 Scheduler 任务/记录交互及会话定位，改进 tabs 横向滚动和 Codex 用量摘要。
- 修复连续鼠标点击投递问题；中文输入、授权撤销及超时恢复经过真实夹具验证。

## 更新

Windows x64 安装包随附签名更新清单。使用 stockloom-2026-r2 更新公钥的版本（beta.7及之后）可检查应用内更新；更早版本请手动下载安装包。安装包本身未作商业代码签名。

## 已知情况

- 历史 UIA 写入偶发超时尚未定位根因，最近五轮完整输入及包内回归未复现；已增加阶段诊断和执行端回收。超时后应重新观察，避免直接重复不确定的操作。
- 本轮验证覆盖100%、150%、175%缩放；200%、多屏及独立机器安装测试暂缓。
- Windows SDK 依赖许可原文随包提供，Microsoft.Windows.SDK.NET.dll具体再分发范围仍待核实；维护者决定继续使用当前依赖。本记录不表示已确认许可范围。

本版本保留现有股票数据和配置；Computer Use 按授权应用及实际操作能力工作。发布不等同于所有环境验收完成。
