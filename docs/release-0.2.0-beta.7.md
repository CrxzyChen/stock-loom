# Stock Loom 0.2.0-beta.7

- 修复多个会话同时使用浏览器时争用项目配置目录的问题，采用 Playwright MCP 原生隔离上下文。
- 浏览器会话之间不共享登录状态；关闭浏览器后该会话的登录状态不保留。
- 修复资料库版本不支持等启动异常被静默吞掉的问题，显示可操作的错误提示，保留原资料。

沿用 beta.6 的数据库格式（schema 10），不新增迁移。原更新密钥丢失，本版换用 stockloom-2026-r2。beta.6 及更早版本必须从本发布页手动下载安装；不要卸载或删除资料。安装 beta.7 后，后续版本恢复应用内更新。新清单仍执行签名及安装包哈希校验。安装包未使用 Windows 商业代码签名。

验证：15 项针对性 Node 测试通过；真实 Edge 双 MCP 客户端并发、存储隔离、独立关闭与重开验证通过。未执行异机安装测试。
