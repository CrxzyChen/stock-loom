# Stock Loom · 观市 v0.1.0-beta.1

2026-09-12，用户接受当前功能作为首个 Beta。本次提交收口源码；安装包下载以 GitHub Releases 中实际上传的资产为准。

## 本版变化

- 支持31个Tushare接口，新增公司与经营资料、管理层、曾用名、风险名单、IPO、业绩预告/快报、财务指标和主营构成；支持按需缓存与分页，保留数据来源、日期和单位。
- 持仓账本支持买卖、费用、修订与幂等写入；旧持仓迁移为期初余额，新增组合盈亏和行业分布。
- 完善Copilot审批、会话与调度状态反馈，支持调度历史轮次定位。
- 中央Tabs增加右键和批量关闭，保护草稿并恢复布局；修复个股排行引发的空白滚动。
- 完善更新清单校验、下载、取消和安装前协调，补齐使用、贡献和恢复说明。

## 验证

224项Node与242项Python测试通过，类型检查、273个共享类型及99个RPC请求/响应映射通过。隔离Electron覆盖核心交互；新增资料接口进行了真实账号小范围请求和公开样本校验。上述验证不等于所有数据权限或所有Windows环境均可用。

## 已知限制

- 盈利前不配置Windows代码签名，安装包可能显示未知发布者。仅支持Windows x64。
- 正式更新公钥尚未部署，应用内可信更新尚未完成真实发布闭环；当前使用Releases手动安装更新。
- 异机安装、新用户独立验收和跨交易日完整旅程尚未完成，本次Beta接受这些已披露限制，不补造验收记录。
- 公告、盘前股本、ST风险警示详情在当前测试账号中缺少权限；每位用户的数据权限取决于自己的Tushare账号。
- 日线及财务快照不是实时交易终端；不连接券商下单。持仓记录不等于真实交易。
- 数据库schema9，升级前建议备份；资料库备份不含凭证、Codex会话和项目文件，详见[兼容说明](../COMPATIBILITY.md)。
