# Stock Loom 0.2.0-beta.8

- 换用全新 Stock Loom Logo，统一标题栏、窗口、托盘、Windows 应用和安装器图标。
- 修复 Codex 无法修改定时任务审批权限的问题，支持请求批准、帮我审批和完全访问权限。
- 修改定时任务其他字段时保留原权限；权限调整从下次任务运行生效，不改变正在运行的会话。

beta.7 可通过应用内预览渠道更新。沿用 stockloom-2026-r2 更新签名及 schema 10 数据格式，无需重建资料库。beta.6 及更早版本因旧签名密钥丢失，需从发布页手动安装一次，不要删除原资料。

验证：调度、托盘、更新签名及安装流程测试，类型检查与 Windows 包内运行时验证。未执行异机安装测试。安装包不含 Windows 商业代码签名，更新清单签名及文件哈希校验仍保留。
